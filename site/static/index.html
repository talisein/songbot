Concert Data

This site stores static reference data about Hatsune Miku live concerts: songs, setlists, upcoming shows and rhythm-game track lists. It has no API, only the JSON files below, regenerated from songbot whenever its data changes.

Every file has the same envelope:

{ "schema_version": 1, "data": [ ... ] }

Within a schema version, fields are only ever added. A removed or renamed field bumps schema_version. Fields marked optional are omitted when absent, never null. Enum values are uppercase identifiers such as MIKU_EXPO; dates are ISO 8601. Files are served with Access-Control-Allow-Origin: * and cached for five minutes. vocadb_* ids refer to VocaDB entries.

/songs.json

Every song that has been performed at a covered concert or appears in a covered game.

FieldTypeNotes
namestringEnglish title. With producer, this is how setlists and game tracks refer to a song.
jp_namestring optionalOriginal title
romaji_namestring optional
producerstring
singersstring[]Main virtual singers: Miku Rin Len Luka MEIKO KAITO Teto Gumi. Empty for non-vocaloid pieces.
minor_rolesstring[] optionalSingers in supporting parts
vocadb_idinteger optionalVocaDB song id
disambiguationstring optionalDistinguishes songs that share a name

  "jp_name": "千本桜",
  "name": "Thousand Cherry Blossoms",
  "producer": "Kurousa-P",
  "romaji_name": "Senbonzakura",
  "singers": ["Miku"],
  "vocadb_id": 8394
}

/concerts.json

One entry per concert or tour, with its setlist.

FieldTypeNotes
tourstringUnique key, e.g. ME2026NA. Used by events.
tour_displaystringShort display name, e.g. MM10th
seriesstringMIKU_EXPO, MAGICAL_MIRAI, SNOW_MIKU, MIKU_WITH_YOU, MIKUPA, ...
namestringFull official name
datedateFirst show
last_datedate optionalLast show, for multi-day runs and tours
vocadb_event_idinteger optionalVocaDB release event id
setlist[].posinteger1-based. Repeats when shows rotate songs in the same slot.
setlist[].songstringMatches songs[].name
setlist[].producerstring optionalPresent only when the name alone is ambiguous
setlist[].variantstring optionalWhich rotation, e.g. Set A
setlist[].remixstring optionale.g. -Reloaded-
setlist[].remix_idinteger optionalVocaDB id of the remix
setlist[].song_vocadb_idinteger optionalThe matched song's vocadb_id, for joining

/events.json

Individual scheduled shows with exact start times.

FieldTypeNotes
tourstringMatches concerts[].tour
vocadb_event_idintegerVocaDB event; per city for tours
start_localstringWall-clock time at the venue, no offset
start_utcstringISO 8601 in UTC
start_unixintegerSeconds since the Unix epoch
tzstringIANA time zone of the venue
duration_minutesintegerExpected show length; 120 unless known otherwise
location_namestringVenue
location_linkstringMap link
